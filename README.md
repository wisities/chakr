# ระบบคำนวณและ QC วีลแชร์สำหรับสัตว์พิการ (Wheelchair for Pets)
**โครงการเพราะมีน้ำใจจึงมีชีวิต มูลนิธิศาสตราจารย์ ดร.จักร พิชัยรณรงค์สงคราม**

เว็บแอปพลิเคชันสำหรับคำนวณขนาดการตัดท่อ PVC, สรุปรายการอุปกรณ์ และตรวจสอบคุณภาพ (QC) หลังประกอบ สำหรับวีลแชร์สัตว์พิการ (สุนัขและแมว) ทั้งแบบ 2 ล้อหลัง และ 4 ล้อเต็มตัว

---

## 🌟 ฟีเจอร์หลัก (Key Features)
1. **ระบบคำนวณอัตโนมัติตามสัดส่วนสัตว์ ($A, B, G, H, E, D$):**
   * คำนวณขนาดชิ้นส่วนท่อที่ต้องตัด **ก, ข, ค, ง, จ, ฉ, ช** พร้อมระบุจำนวนชิ้นและสูตรที่มา
   * เลือกรุ่นวีลแชร์ได้ 6 รูปแบบ (3 ขนาดท่อ $\times$ 2 แบบล้อ)
2. **ระบบคัดกรองขนาดท่อ PVC อัตโนมัติ:**
   * แมว $\rightarrow$ บังคับใช้ขนาด 3 หุน ทั้งหมด
   * สุนัข $\rightarrow$ $1-5\text{ กก.}$ (3 หุน), $6-10\text{ กก.}$ (4 หุน), $>10\text{ กก.}$ (6 หุน)
   * รองรับการปรับเปลี่ยนขนาดท่อเองโดยผู้เชี่ยวชาญ (Manual Override)
3. **ไดอะแกรมโครงสร้างและจุดวัดตัว (Interactive Visuals):**
   * แสดงภาพตำแหน่งการวัดตัว $A, B, G, H, E, D$ บนตัวสัตว์
   * แผนผังโครงสร้างวีลแชร์แบบ Interactive ชี้เพื่อไฮไลต์ตำแหน่งท่อแต่ละชิ้น
4. **ระบบตรวจรับงานและควบคุมคุณภาพหลังประกอบ (QC Inspection):**
   * ตรวจสอบระยะช่วงตัว ($= E$)
   * ตรวจสอบความสูงระดับกึ่งกลางท่อ ($= (A+B)/2$)
   * ตรวจสอบความกว้างด้านในท่อ ($= G + 1, 2, 3$ ตามขนาดท่อ)
   * ตรวจสอบความสูงคานหน้าอก ($= D - 4, 5, 6$ ตามขนาดท่อ)
   * แสดงสถานะผ่านเกณฑ์ (Pass / Fail) พร้อมอนิเมชันเฉลิมฉลองเมื่อผ่านครบ 100%
5. **ใบงานช่างสั่งพิมพ์ขนาด A4 (Print / Export PDF):**
   * จัดเลย์เอาต์หน้าพิมพ์สำหรับช่างตัดท่อและใบตรวจรับรอง QC พร้อมช่องลงชื่อ
6. **ระบบบันทึกประวัติเคส (Saved Cases):**
   * บันทึกเคสในเบราว์เซอร์ และส่งออก/นำเข้าเป็นไฟล์ JSON
### 7. การเชื่อมต่อกับ Google Sheet ของโครงการ
* บันทึกข้อมูลไปยัง [Google Sheet ของโครงการ](https://docs.google.com/spreadsheets/d/1EJASDHMSzbnt2mdlALjvwgmA8HkIiuHQGwlahMr44gg/edit?usp=sharing)
* บันทึกข้อมูลครบถ้วน: **Case ID, วันเวลา, ชื่อ Staff, ชื่อสัตว์, ชื่อเจ้าของ/เบอร์ติดต่อ, ชนิดสัตว์, น้ำหนัก, สัดส่วน A-D, E, G, H, รูปแบบวีลแชร์, ขนาดท่อ, ความยาวและจำนวนชิ้นส่วน ก - ช, ความยาวท่อรวม, สถานะ QC**
* **ระบบค้นหาและดึง Case ID เพื่อแก้ไข:** สามารถพิมพ์ Case ID เพื่อดึงข้อมูลเดิมจาก Google Sheet กลับมาแก้ไขในเว็บและบันทึกอัปเดตทับแถวเดิมได้ทันที (UPSERT by ID)

## 📋 วิธีการติดตั้ง Google Apps Script (เชื่อมกับ Google Sheet)

1. เปิด [Google Sheet โครงการ](https://docs.google.com/spreadsheets/d/1EJASDHMSzbnt2mdlALjvwgmA8HkIiuHQGwlahMr44gg/edit?usp=sharing)
2. ไปที่เมนู **"ส่วนขยาย" (Extensions) > "Apps Script"**
3. ลบโค้ดเดิมทั้งหมดออก แล้วคัดลอกโค้ดจากไฟล์ `google_apps_script.js` ในโปรเจกต์นี้ไปวาง
4. กดปุ่ม **"การทำให้ใช้งานได้" (Deploy) > "การทำให้ใช้งานได้รายการใหม่" (New deployment)**
5. เลือกประเภท: **"เว็บแอป" (Web App)**
   * **คำอธิบาย:** Wheelchair Calc API
   * **ดำเนินการในฐานะ:** ฉัน (Me)
   * **ผู้ที่มีสิทธิ์เข้าถึง:** ทุกคน (Anyone) *(สำคัญ เพื่อให้เว็บแอปส่งข้อมูลเข้าได้)*
6. กด **"ทำให้ใช้งานได้" (Deploy)** แล้วคัดลอก **Web App URL** (ลงท้ายด้วย `/exec`)
7. นำ Web App URL ไปวางในหน้าเว็บแอป (กดปุ่ม "ค้นหา Case ID / ตั้งค่า Google Sheet" บนแถบเมนู)

## 📐 สูตรและค่าคงที่การคำนวณ

### ค่าคงที่ (Constants)
* **3 หุน:** รัศมีล้อหลัง $= 5.5\text{ cm}$, ความสูงล้อหน้า $= 5.0\text{ cm}$, ตัวหักขนาดท่อ $= 3\text{ cm}$
* **4 หุน:** $X = 2.0$, $Y = 8.5$, $Z = 2.5$, รัศมีล้อหลัง $= 7.0\text{ cm}$, ความสูงล้อหน้า $= 6.5\text{ cm}$, ตัวหักขนาดท่อ $= 4\text{ cm}$
* **6 หุน:** $X = 2.25$, $Y = 10.0$, $Z = 3.0$, รัศมีล้อหลัง $= 9.5\text{ cm}$, ความสูงล้อหน้า $= 8.0\text{ cm}$, ตัวหักขนาดท่อ $= 6\text{ cm}$

### สูตรการตัดชิ้นส่วน (หน่วย: เซนติเมตร)
* **2 ล้อ (3 หุน):** $ก = G - 6$ (2 ชิ้น), $ข = ((A+B)/2) - 5.5 - 3$ (4 ชิ้น), $ค = 3$ (2 ชิ้น), $ง = (E-7.5)/2$ (4 ชิ้น), $จ = ((A+B)/2) - D - 3$ (2 ชิ้น), $ฉ = 6$ (2 ชิ้น)
* **2 ล้อ (4 & 6 หุน):** $ก = G$ (2 ชิ้น), $ข = ((A+B)/2) - R_{rear} - (4 หรือ 6)$ (4 ชิ้น), $ค = 2X+3$ (2 ชิ้น), $ง = (E-2Y+4X)/2$ (4 ชิ้น), $จ = ((A+B)/2)-D$ (2 ชิ้น), $ฉ = 2X$ (2 ชิ้น)
* **4 ล้อ (3 หุน):** $ก = G - 6$ (2 ชิ้น), $ข = ((A+B)/2) - 5.5 - 3$ (4 ชิ้น), $ค = 3$ (4 ชิ้น), $ง = E - 12$ (2 ชิ้น), $จ = ((A+B)/2) - D - 3$ (2 ชิ้น), $ฉ = 6$ (4 ชิ้น), $ช = ((A+B)/2) - 5 - 3$ (4 ชิ้น)
* **4 ล้อ (4 & 6 หุน):** $ก = G$ (3 ชิ้น), $ข = ((A+B)/2) - R_{rear} - (4 หรือ 6)$ (4 ชิ้น), $ค = 2X+3$ (4 ชิ้น), $ง = (E-2Y+4X)/2$ (4 ชิ้น), $จ = ((A+B)/2)-D$ (4 ชิ้น), $ฉ = 2X$ (4 ชิ้น), $ช = ((A+B)/2) - Z - H_{front} - (4 หรือ 6)$ (4 ชิ้น)

## 🌐 การนำขึ้น GitHub และ Host บน Vercel

### วิธีที่ 1: Deploy ผ่าน GitHub (แนะนำ)
1. นำโค้ดขึ้น GitHub Repository ของท่าน:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Wheelchair for Pets Calculator & QC App"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<your-repo-name>.git
   git push -u origin main
   ```
2. เข้าสู่ระบบ [Vercel Dashboard](https://vercel.com)
3. กด **Add New Project** $\rightarrow$ เลือก Repository จาก GitHub
4. Vercel จะตรวจพบการตั้งค่า Vite โดยอัตโนมัติ $\rightarrow$ กด **Deploy**

### วิธีที่ 2: Deploy ด้วย Vercel CLI
```bash
npm install -g vercel
vercel
```
